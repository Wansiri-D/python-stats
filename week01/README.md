# Week 01: Python Fundamentals

Coursework for **Pythonprogrammering och statistisk dataanalys** at EC Utbildning.  
This week covers Python basics, data structures, control flow, loops, and a collaborative mini-quiz lab.

---

## 📌 Topics Covered
- **Variables & Data Types**: `int`, `float`, `str`, `bool`
- **Arithmetic Operators & Strings**: Slicing, search, replace, and f-strings
- **Control Flow**: `if`, `elif`, `else` conditions
- **Lists**: Indexing, slicing, list methods, and iterations
- **Loops**: `for` and `while` loops, avoiding infinite loops
- **Debugging**: Resolving syntax, logic, and type conversion errors
